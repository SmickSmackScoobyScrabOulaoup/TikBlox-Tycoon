TikBlox Tycoon

Une expérience Roblox qui permet aux joueurs de connecter volontairement leur compte TikTok afin d'afficher les informations et vidéos TikTok auxquelles ils ont autorisé l'accès.

Comment ça fonctionne ?

Le joueur choisit de connecter son compte TikTok. Après l'autorisation sur TikTok, TikBlox Tycoon utilise les autorisations accordées pour récupérer les informations nécessaires à l'expérience, notamment les informations de profil de base et les vidéos publiques disponibles via les API TikTok autorisées.

Le jeu propose ensuite une expérience de type flux vidéo, une monnaie virtuelle et des améliorations de progression dans Roblox.
